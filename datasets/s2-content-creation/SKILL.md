## Skill 详细说明

### 素材获取层（3个）

| 别名 | 来源Skill | 功能 |
|------|----------|------|
| web-scraper | Agent Browser | AI驱动的浏览器自动化，网页抓取 |
| image-search | Image AI Kit | 图片搜索与AI处理 |
| trend-analyzer | Startup Idea Validator | 竞争分析与趋势洞察 |

### 内容生产层（7个）

| 别名 | 来源Skill | 功能 |
|------|----------|------|
| article-writer | Writing Plans | 文章撰写规划 |
| audio-synthesizer | Jarvis Vocal | 语音合成与TTS |
| video-editor | Audio Video | 音视频处理 |
| ppt-generator | AI PPT Generator | AI生成PPT演示文稿 |
| content-writer | Content Writer | 自媒体内容生成器 |
| blog-writer-pro | Blog Writer Pro | 博客写作专业版 |
| video-editor-1 | Video Editor | 专业视频编辑器 |

### 内容优化层（3个）

| 别名 | 来源Skill | 功能 |
|------|----------|------|

| content-translator | PDFMathTranslate | 多语言内容翻译 |
| watermark-adder | Image Processor | 图片处理与水印 |
